> show shell command (this is the command that was run) 
powershell.exe -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File ".\Start-Autosheet-Playtest-Kit.ps1"
> explain (this is what it does)
  • Runs a local loopback static server on 127.0.0.1:38173 serving files exclusively from this Playtest Kit folder.
  • Checks playtest-state.json / browser crash log #inits: on run 1 (0) opens a private window to this warning, then switches to regular --app= mode on run 2+ (1).
  • -NoProfile -ExecutionPolicy Bypass executes only the bundled launcher script without altering Windows settings or installing services.

Serious Note — Hardening & Windows Defender Firewall

Current hardening note: full dev server.ts binds 0.0.0.0 — use a firewall or a reverse proxy. (This standalone Playtest Kit static host binds loopback 127.0.0.1:38173 only.) Make sure Windows Defender Firewall is ON. Full dev hosting uses your own network and port 3000 (don't know what that is? Then it's probably open or firewall-managed).
